# Testing strategy

Unit tests cover product validation, serving scaling, date cutoff, aggregation, empty plans, archived references, API error mapping, auth headers, R2 URL/config mapping, signed-upload path ownership, and repository contracts. Component tests cover product forms, calendar actions, recipe loading errors, shopping states, and responsive shell navigation. Playwright covers the authenticated REST flow from login through recipes, products, plan, shopping list, and recipe-photo creation. Set `E2E_EMAIL` and `E2E_PASSWORD` to run that smoke flow; without them the test is intentionally skipped rather than attempting an unauthenticated data flow.

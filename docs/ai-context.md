# AI context

Meal Planner is a mobile-first, server-backed Ukrainian PWA. Supabase Auth identifies users; system recipes/products are read-only and personal recipes/products/plans are private. After authentication, users enter Today directly and can add a first meal from Today or Plan. Products are minimal (`name`, controlled `category`, `baseUnit`), recipes reference products and may omit a personal photo, and `/plan` stores date/slot/recipe per user. `/shopping` is a ranged derived view whose default is the next seven days; its product demand starts from one serving per planned recipe, while temporary source serving adjustments have no server persistence, checks are local to the authenticated browser and exact range, and it has no purchases, prices, snapshots, or manual rows. Archived entities remain readable in historical records. The PWA shell can be installed, but authentication and server data changes require connectivity.

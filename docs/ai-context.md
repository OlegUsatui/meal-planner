# AI context

Meal Planner is a mobile-first, server-backed Ukrainian PWA. Supabase Auth identifies users; system recipes/products are read-only and personal recipes/products/plans are private. Onboarding leads directly to a first planned system recipe. Products are minimal (`name`, controlled `category`, `baseUnit`), recipes reference products and may omit a personal photo, and `/plan` stores date/slot/recipe/servings per user. `/shopping` is a ranged, read-only derived view whose default is the next seven days; it has no persistence, checks, purchases, prices, snapshots, or manual rows. Archived entities remain readable in historical records. The PWA shell can be installed, but authentication and server data changes require connectivity.
